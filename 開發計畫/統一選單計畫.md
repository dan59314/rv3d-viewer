# PlugIn 選單修改計畫

## 修改目標

檢查所有 PlugIn，並為每個 PlugIn 加入統一的選單結構。

## 選單結構與功能

### 檔案

- **讀取**
  - 將各 PlugIn 內所有與讀取檔案相關的功能，統一新增至此選單。
- **儲存**
  - 將各 PlugIn 內所有與儲存檔案相關的功能，統一新增至此選單。

### 編輯

- 保留「編輯」選單，供各 PlugIn 加入相關編輯功能。

### 顯示

- **Camera**
  - 控制是否顯示相機。
- **燈光**
  - 控制是否顯示燈光。
- **貼圖**
  - 控制是否顯示貼圖。
- **模型**
  - **點雲**：以點的方式顯示模型。
  - **線框**：以線框的方式顯示模型。
  - **實體**：以填滿面的方式顯示模型。

### 說明

- **關於**
  - 參考 `MainForm` 的 About 視窗。
  - 第一行顯示目前的 PlugIn 名稱。
  - 其餘內容與 `MainForm` 的 About 視窗相同。
- **教學**
  - 參考 `MainForm` 的處理方式。
  - 掃描目前 PlugIn 目錄下的 `Tutorials` 資料夾。
  - 依資料夾與檔案階層，以樹狀結構動態加入「教學」選單。

## 選單階層總覽

```text
檔案
├── 讀取
└── 儲存

編輯

顯示
├── Camera
├── 燈光
├── 貼圖
└── 模型
    ├── 點雲
    ├── 線框
    └── 實體

說明
├── 關於
└── 教學
    └── 依 Tutorials 目錄內容建立樹狀選單
```
