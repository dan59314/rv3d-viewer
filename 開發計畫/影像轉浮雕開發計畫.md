# 2.5D 浮雕模型 PlugIn 實作計畫

## 摘要

新增 `Rv3dViewer.PlugIn_Relief` WinForms 外掛，支援 JPG、PNG、BMP、TIFF、WebP 圖檔，提供影像處理、離線 AI 相對深度推論、灰階高度場轉換、左右對稱，以及與 MainForm 相同的 OpenGL Render 和滑鼠操作。

採用 Apache-2.0 授權的 Depth Anything V2 Small 作為離線相對深度模型，透過 ONNX Runtime CPU 執行，不上傳圖片；結果代表正規化相對深度，不宣稱為毫米級掃描資料。[Depth Anything V2](https://github.com/DepthAnything/Depth-Anything-V2)、[ONNX Runtime C#](https://onnxruntime.ai/docs/get-started/with-csharp.html)

## 主要實作

- 建立外掛專案、`plugin.json`、部署規則與外掛選單命令「建立 2.5D 浮雕模型」；加入 Solution，參考 Core、Plugin Abstractions 與共用 OpenGL Renderer。
- 建立 Designer 管理的 `ReliefBuilderForm` 與 `.resx`，所有固定控制項、版面和事件綁定均放在 `.Designer.cs`，不改動 MainForm 既有 UI、DPI 或樣式。
- 視窗配置參數區及三個 TabPage：
  - 「原始影像」：縮放顯示載入圖片。
  - 「處理後影像」：顯示實際送入高度場的灰階/深度圖。
  - 「2.5D 模型」：Designer 內放置 `GLControl`，使用 `OpenGlRenderer` 顯示暫存場景。
- 幾何參數包含：成品總寬、總厚度、邊框寬度、浮雕高度；驗證 `0 < 浮雕高度 <= 總厚度`、`0 <= 邊框 < min(寬,高)/2`。
- 指定寬度包含邊框，成品外高依原圖比例計算；底層厚度為「總厚度－浮雕高度」，黑色對應最低浮雕面，白色對應總厚度上限。
- 圖片維持原比例映射到整個正面；邊框區保持平面，內部區依灰階升高。建立具底面、外側面、平坦邊框及浮雕正面的封閉、可儲存程序化模型。
- 正面使用原始彩色像素作 BaseColor 貼圖；WebP 等格式先無損轉存為 PNG 工作貼圖，灰階處理圖只控制幾何，不取代彩色貼圖。加入場景後由既有專案儲存流程將貼圖收進 `Assets/Textures`。
- 網格品質提供：
  - 草稿：內部最長邊 128 點。
  - 標準：256 點，預設。
  - 精細：512 點。
  - 另一軸按圖片比例計算，並設最大點數與記憶體防護。
- 以共享頂點規則網格、三角形索引、有限差分法線及 UV 建立模型；參數或處理結果改變後，以 debounce、取消前次工作及背景計算更新預覽，OpenGL 更新回到 UI 執行緒。

## 影像與深度流程

- 載入時套用圖片方向資訊並建立原始像素快照；支援灰階、HSV 色相/飽和度/明度調整及降色階數。
- 一般模式依調整後亮度建立 0–1 灰階高度；提供反相控制，以處理「白高黑低」或「黑高白低」圖案。
- 「真實灰階深度」勾選後，使用隨外掛部署的 Depth Anything V2 Small ONNX 模型推論相對深度，正規化並轉為白近、黑遠的高度圖；模型缺失或推論失敗時顯示錯誤，但一般灰階模式仍可使用。
- 「左右對稱」在深度/灰階產生後執行：以可調整的垂直中心線為軸，將左右像素平均並鏡射；中心線預設為圖片 50%。
- 處理順序固定為：方向校正 → HSV → 一般灰階或 AI 深度 → 正規化/反相 → 左右平均對稱 → 降色 → 網格取樣。
- 保留原始彩色貼圖、處理後灰階 Bitmap 與最新有效 `SceneModel` 三份獨立狀態，避免預覽更新破壞來源影像。

## ViewPort 與關閉流程

- 外掛預覽建立只含當前浮雕模型的暫存 `ViewerProject`，使用共用 `OpenGlRenderer`、預設燈光與自動置中相機。
- 操作完全沿用 MainForm：左鍵 Orbit、中鍵移動 Camera Target、右鍵 Pan、滾輪調整 FOV；Render 設定、材質貼圖、網格與座標方向使用同一實作。
- 關閉視窗且已有有效模型時顯示「是否將模型加入 MainForm 場景？」：
  - 是：回傳最新模型，外掛加入 `context.Project.Models`，呼叫 `NotifySceneChanged()` 並更新狀態列。
  - 否：關閉但不修改場景。
  - 取消：中止關閉並保留編輯視窗。
- 無有效模型時直接關閉；同一次視窗生命週期只允許加入一次，避免重複模型。

## 介面與相容性

- 不修改既有 `IPluginContext` 或 Host API；直接沿用 `SceneModel`、`PbrMaterial`、`TextureSlot` 與 `OpenGlRenderer`。
- 新增外掛內部參數型別、影像處理器、ONNX 深度服務、浮雕網格產生器及表單狀態模型。
- 外掛部署包含 ONNX Runtime x64 原生檔、Small 模型、Apache-2.0 授權與第三方聲明；仍維持專案既有 x64、.NET 8 WinForms 設定。

## 測試與驗收

- 單元測試尺寸驗證、總厚度上限、邊框範圍、黑白高度映射、反相、HSV、降色及左右平均對稱。
- 驗證草稿／標準／精細的頂點與索引數、UV 範圍、法線有限值、三角形方向、封閉邊界及程序化模型儲存/還原。
- 驗證 ONNX 模型輸入輸出、正規化範圍、取消操作、模型缺失及推論失敗的降級行為。
- 使用 `Gray02.jpg` 驗證普通灰階浮雕與降色；使用 `Gray03.webp`、`Gray04.webp` 驗證 WebP、AI 人像深度、左右對稱及原圖彩色貼圖。
- 手動驗收三個 TabPage、即時更新、MainForm 同款滑鼠操作，以及關閉時「是／否／取消」三條流程。
- 執行完整 x64 Debug/Release Build、既有測試及 Designer 完整性測試，確認沒有改動 MainForm 版面或 DPI 行為。

## 假設與預設

- 「真實深度」定義為單張照片推論出的相對深度，不是實際毫米深度。
- 成品寬度包含邊框；成品高度依原圖比例；總厚度包含底層與浮雕。
- 預設標準品質、白色較高、AI 深度關閉、左右對稱關閉、中心線 50%。
- 第一版只負責建立並加入 Viewer 場景，不另外提供 STL/OBJ 匯出；後續可使用 Viewer 既有模型處理或另增匯出功能。
